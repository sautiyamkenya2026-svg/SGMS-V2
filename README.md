# Golden Automotive Solutions

Smart garage management system built with Vite, React, and Supabase.

## Quick setup

- Install dependencies: `pnpm install` (or `npm install`)
- Run dev server: `pnpm dev` (or `npm run dev`)
- Build for production: `pnpm build` (or `npm run build`)

This repository uses Supabase for backend services, including storage for uploads and signed URLs for private files.
